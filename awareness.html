Cybersecurity attack example

Hi, This was just a stimulated quishing act

The tournament website you just visited was created for an educational cybersecurity demonstration.

you trusted this website, and clicked on a trounoament banner without knowing exactly where it would take you.

No personal information was requested, collected, or stored during this demonstration.

So, What Just Happened?

1. You Saw a QR Code

There was a QR code in the Tournament flyer.

2. You Scanned It

The QR code directed you to a website that looked like a legitimate website in my case this looked like the "diamond web page".

3. You Trusted the Website

Since the website looked the same as the original one, it caused you to think this is a valid website.

4. You Clicked the Tournament

Instead of tournament registration, you were brought to this cybersecurity awareness page.

What If This Were a Real Attack?

A malicious QR code could direct a victim to a website designed to steal sensitive information.

This technique is known as quishing, or QR code phishing.
